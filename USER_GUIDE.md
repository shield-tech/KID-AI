# K.I.D User Guide

## Overview

K.I.D is a local-first assistant for Linux Mint. It is designed to operate entirely on the machine, using local inference through Ollama and local file storage.

## Interface

- Model selection menu
- Hardware status panel
- Local Ollama connection status
- Memory warnings and resource checks
- Conversation transcript area

## Using the app

1. Ensure Ollama is installed and running.
2. Install the desired models locally with Ollama.
3. Start K.I.D with `kid`.
4. Select the model from the installed-model dropdown.
5. Type a prompt and receive a local response.

## Limitations

- The current release does not implement full voice streaming or autonomous computer operations.
- It remains intentionally conservative and security-minded.
